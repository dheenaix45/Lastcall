# LastCall

Turning closing-time kitchen leftovers into meals, before the safe window runs out.

## Problem
Commercial kitchens throw away large batches of prepared hot food at closing because redistributing perishable food within safe temperature windows lacks coordination.

## Solution
Kitchens post surplus food in seconds. NGOs see it with a live safety countdown and claim it before it becomes unsafe.

## SDGs
- SDG 12: Responsible Consumption and Production
- SDG 2: Zero Hunger

## Features
- Kitchen page: post surplus food (name, meals, pickup address, cooked time)
- NGO page: live list with a safe-time countdown and one-click claim
- Impact counter: total meals saved

## Tech stack
Next.js, TypeScript, Tailwind CSS

## Run locally
cd app
npm install
npm run dev
Then open http://localhost:3000
